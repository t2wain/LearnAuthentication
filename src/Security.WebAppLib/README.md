This project is created based on the Visual Studio template "Asp.Net Core Empty". The intention of this project is to be a reference library and not a running application. The primary reason for using this template is to have access to all the .NET assemblies needed for the Identity, Authentication, and Authorization logics instead of adding individual Nuget libraries. This ensure that all the .NET assemblies are of the same version and compatible with one another. These .NET assemblies are included by the Microsoft.AspNetCore.App framework.
